# Insurance Claimants Classification & Decision Tree Modeling

A machine learning classification pipeline predicting whether an insurance claimant engages legal counsel (ATTORNEY), featuring hyperparameter optimization with GridSearchCV, tree visualization, and ROC-AUC evaluation.

## 📌 Project Overview

Legal representation impacts both claim duration and settlement payout amounts. This project analyzes demographic and loss data from claimants.csv to classify whether a claimant is represented by an attorney.
